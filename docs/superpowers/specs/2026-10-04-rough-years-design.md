# 世紀単位の年と主題「国家・体制など」 設計書

- 作成日: 2026-10-04
- 状態: レビュー待ち
- 前提: [2026-09-29-subjects-and-periods-design.md](./2026-09-29-subjects-and-periods-design.md)（以下「主題の spec」）、[2026-10-03-source-panel-design.md](./2026-10-03-source-panel-design.md)（以下「出典パネルの spec」）、data リポの spec `2026-10-04-ancient-orient-scope-design.md`（以下「data リポの spec」）

## 1. 目的

古代オリエントのデータを足すと、出典の記事が始まりや終わりを世紀までしか書いていない項目（エジプト中王国「前 2040 年頃〜前 18 世紀頃」など）と、国家ではない文明（クレタ文明など）が入る。

- 世紀単位の値を、確かめられない年を見せずに描く。棒の端に幅を持たせ、幅の部分をぼかす
- 主題「国家・体制」に文明なども入るので、名前を「国家・体制など」にする（data リポの spec §3）

成功の基準:

- 世紀単位の端を持つ棒が、確かな区間は今と同じ濃さで、幅の部分は外側に向かって薄く描かれる
- 期間の文字が「前2040頃–前18世紀頃」の形で、棒・棒の外のラベル・出典パネルに出る
- 表示（主題 4 つ・国・地域 9 つ）× 向き 2 通りのすべてで、棒とラベルが重ならず、棒の中の文字が読める

## 2. スコープ

### 含めるもの

- 成果物の `Year` に世紀・千年紀の形を足し、読み込みで検証する（§3）
- 世紀単位の端の位置・段分け・描き方（§4）
- 期間の文字の形式（§5）
- 主題「国家・体制」の名前を「国家・体制など」にする（§6）

### 含めないもの

- 種類の値（`regime`）や、主題の並びの変更
- 出来事（点や短い期間）の表示（data リポの spec §2）

## 3. データ（成果物）

主題の spec §3 から変えるところだけ。形と幅の決め方は data リポの spec §5 と同じ。

```ts
type Part = "early" | "middle" | "late" | "first-half" | "second-half";
type Year =
  | { year: number; circa: boolean }
  | { century: number; part: Part | null; circa: boolean } // 紀元前は負の数
  | { millennium: number; part: Part | null; circa: boolean };
```

- 読み込み: どの形かはキーで決まる。キーの過不足、0 の `century`・`millennium`、知らない `part` は、ほかの検証の失敗と同じく読み込まずにエラーにする
- 期間の検証（開始が終了より後）は、幅で比べる（開始のいちばん早い位置が、終了のいちばん遅い位置より後なら弾く）
- 幅（`bounds(year): { from: number; to: number }`）は、年なら `from = to = year`、世紀・千年紀なら data リポの spec §5 の幅

## 4. 表示

**位置**: 棒の外形は、開始の幅の `from` から終了の幅の `to` まで。確かな区間（濃く描く区間）は、開始の幅の `to` から終了の幅の `from` まで。年の端なら幅がないので、今と同じ位置になる。

- 確かな区間がない（開始の `to` が終了の `from` より後。「前 26 世紀頃」1 つだけの在位など）ときは、外形の中ほどの 1 点を最も濃い位置にし、両側に向かって薄くする
- 終わりが `null`（現在まで）の棒は今と同じ

**描き方**: 幅の部分は、外側の端で透明になり、確かな区間の端で棒の色になるグラデーションにする。棒の色（`bg-bar-a`・`bg-bar-b`）を背景のグラデーションで描き、選択したときの枠は外形全体に付ける。

**段分けと範囲**: 段分け（`assignTracks`）・年の範囲（`timeRange`）・並び（開始の早い順）は、外形で決める。ぼかした部分どうしも重ならない。

**棒の中の文字**: 棒の中に入れるかどうかは、確かな区間の長さで決め、文字は確かな区間の始まりから置く。幅の部分の薄い所に文字を置くと読めないため。確かな区間に収まらなければ、今と同じく棒の外に出す。

**棒の外のラベル**: 今と同じく外形の始まりから置く（主題の spec §4）。

**目盛り**: 年の範囲が紀元前に広がる。目盛りの文字は今と同じ形式（`前100`、`0`、`100`）。

## 5. 期間の文字

| 値 | 文字 |
|---|---|
| `{ century: -27, part: null, circa: true }` | `前27世紀頃` |
| `{ century: -19, part: "early", circa: false }` | `前19世紀初め` |
| `{ century: -17, part: "middle", circa: true }` | `前17世紀半ば頃` |
| `{ century: -8, part: "late", circa: false }` | `前8世紀末` |
| `{ century: 4, part: null, circa: false }` | `4世紀` |
| `{ millennium: -2, part: "second-half", circa: false }` | `前2千年紀後半` |

- 部分の文字: `early` 初め、`middle` 半ば、`late` 末、`first-half` 前半、`second-half` 後半。「頃」は部分の後に付ける
- 期間は今と同じく「開始–終了」。開始と終了が同じ値（形・数・部分・頃がすべて同じ）なら 1 つだけ出す（例: `前26世紀頃`）
- 棒の中・棒の外のラベル・出典パネルの期間（出典パネルの spec）は、どれもこの形式

## 6. UI 文言

主題の spec §5 から変える・足すものだけ。

| 場所 | 文言 |
|---|---|
| 主題の選択肢（国・地域の表示の行の名前も同じ） | 国家・体制など ／ 君主 ／ 首相・大統領など ／ 政権 |
| 年の形式（世紀・千年紀） | §5 の表 |
| 行の名前（データ） | ギリシア ／ エジプト ／ アフリカ ／ シリア・パレスチナ ／ アナトリア ／ メソポタミア ／ イラン（data リポの spec §4） |

## 7. 検証

- Vitest: 読み込み（世紀・千年紀の値、0 の世紀・知らない `part`・キーの混ざった値を弾く、期間を幅で検証）、`bounds`、年の形式（§5 の表、同じ値なら 1 つ）、`timeRange`（外形で範囲をとる）、`layoutLane`（外形での段分け、確かな区間での棒の中の文字、確かな区間がない棒）
- 実ブラウザ（headless Chromium）: PC 幅と 375px 幅のそれぞれで、表示（主題 4 つ・国・地域 9 つ）× 向き 2 通りを確かめる。ぼかしが両方の向きで外側に向かって薄くなること、選択の枠が外形に付くこと、棒の中の文字が確かな区間に収まることを確かめる
