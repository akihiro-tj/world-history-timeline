# Wikipedia 以外の出典 設計書

- 作成日: 2026-10-04
- 状態: 承認済み
- 前提: [2026-10-03-source-panel-design.md](./2026-10-03-source-panel-design.md)（以下「出典パネルの spec」）

## 1. 目的

説が分かれている年では、どの説を採るかと注記に書く理由を、Wikipedia 以外の資料（百科事典・辞典など）で確かめている。利用者がその根拠をたどれるように、根拠にした資料も出典としてパネルに出す。

## 2. データ（成果物）

出典パネルの spec §3 から変えるところだけ。

```ts
type Source = { label: string; url: string | null };
```

- 最初の出典は、値を取った Wikipedia の記事（今までどおり）
- 2 つ目からは、値や注記の理由の根拠にした資料。`url` は `https://` で始まるページか、URL のない資料（本など）の `null`
- 名前（`label`）は「サイト名「記事名」」（例: `Britannica「Knossos」`、`コトバンク「エーゲ文明」`）
- 読み込み: 最初の出典が Wikipedia の記事でない、2 つ目からの `url` が https でも `null` でもないときは、ほかの検証の失敗と同じく読み込まずにエラーにする

## 3. 表示

- 出典はデータの順に並べる（Wikipedia が先）
- `url` があれば今までどおり外部へのリンクにする。`null` なら名前を文字だけで出す
- 同じ URL の出典は 1 つにする。URL のない出典は、名前が同じものを 1 つにする

## 4. 検証

- Vitest: 読み込み（最初の出典が Wikipedia でないものを弾く、2 つ目から Wikipedia 以外の https のページと `null` を読める、https でない URL を弾く）、出典のまとめ方（URL のない出典を名前で 1 つにする）
- 実ブラウザ: PC 幅と 375px 幅で、Wikipedia 以外の出典がリンクとして出ること
