# 主題の 3 分割と期間の表し方 設計書

- 作成日: 2026-09-29
- 状態: 承認済み
- 前提: [2026-09-27-world-history-timeline-design.md](./2026-09-27-world-history-timeline-design.md)（以下「MVP の spec」）、[2026-09-28-lane-view-design.md](./2026-09-28-lane-view-design.md)（以下「国・地域の spec」）

## 1. 目的

データに近世以降の項目（議会・共和政・帝政などの政体、首相・大統領）を足す。これまでの主題「王朝」「王」では、次の 2 つが起きる。

- 「王」の行に、同じ時期の君主と首相（ヴィクトリア女王とディズレーリなど）が混ざる
- 「王朝」の行に、王朝と議会・政府（ブルボン朝と国民議会など）が混ざる

そこで主題を 3 つに分け、あわせて、現在まで続く期間と 1 年だけの期間を表せるようにする。

成功の基準:

- 表示 5 通り（主題 3 つ・国・地域 2 つ）× 向き 2 通りのすべてで、データが欠けや重なりなく表示される
- 1 年だけの棒と、現在まで続く棒が描かれ、期間の文字が §4 の形式になる

## 2. スコープ

### 含めるもの

- 主題を「王朝・政体」「君主」「首相・大統領」の 3 つにする。国・地域の表示も同じ 3 行（縦なら 3 列）にする
- 成果物の在位に役割（`role`）を足す。王朝と在位の終わりを `null`（現在まで）にできるようにする
- 開始と終了が同じ年の期間を 1 年分の長さで描く
- 棒の外のラベルを、段の後ろにまとめず、自分の棒のすぐ外側に置く。縦向きの棒の幅を固定し、列の最小幅を広げる

### 含めないもの

- 政体と議会・政府を別の主題に分けること。王朝・政体の行の中で、期間が重なるものは段を分けて並べる
- 表示の状態を URL に持つこと（旧い値 `subject:reign` との互換も持たない）

## 3. データ（成果物）

MVP の spec §4.2 から変えるところだけ。

```ts
type Role = "monarch" | "leader"; // 君主（王・女王・皇帝）／首脳（首相・大統領・護国卿など）

type TimelineData = {
  lanes: { id: string; name: string; dynasties: string[]; reigns: string[] }[];
  dynasties: { id: string; name: string; start: Year; end: Year | null }[]; // null は現在まで
  people: { id: string; name: string }[];
  reigns: { id: string; personId: string; role: Role; start: Year; end: Year | null }[];
};
```

- 行の `reigns` は役割を問わず並べる。主題「君主」「首相・大統領」は、その行の在位を `role` で絞り込んで出す
- 知らない `role` は、ほかの検証の失敗と同じく読み込まずにエラーにする

## 4. 表示

- **主題**: `Subject = "dynasty" | "monarch" | "leader"`。セレクトの値は `subject:dynasty`・`subject:monarch`・`subject:leader`
- **現在まで**: 終わりが `null` の棒は、アプリを開いた年（`new Date().getFullYear()`）で終わる。年の範囲もその年を含める。開いている間に年が変わっても描き直さない
- **1 年だけ**: 開始と終了が同じ年の棒は、その 1 年分（2px）の長さで描く。段分けもこの長さで行うので、次の年に始まる棒とは同じ段に、同じ年の棒どうしは別の段に並ぶ。棒が短いので、名前と期間は棒の外に出る
- **棒の外のラベルの位置**: MVP ではラベルを棒の段の後ろ（横なら下、縦なら右）にまとめていたが、2 段目の棒がない所でもラベルが棒から離れて見えるので、自分の棒のすぐ外側に置く。そこでほかの棒やラベルと重なるなら、重ならない位置まで外側にずらす（時間軸の順に置いていく）
- **縦向きの棒の幅**: MVP では列の幅を段の数で等分していたが、段とラベルが多い列で棒が細くなり、棒の中の文字が読めなくなるので、1 段の幅を 112px に固定する
- **縦向きの棒の中の文字**: MVP では「名前 期間」を 1 行で入れ、収まらない分を省略記号で切っていたが、年が切れて読めなくなるので切らない。1 行に収まれば 1 行、収まらなくても名前と期間がそれぞれ幅に収まり、棒が 2 行分（34px）の長さなら 2 行に積む。どちらでもなければ棒の外に出す
- **縦向きの列の幅**: 各列の最小幅を「MVP の最小幅 120px」「棒とラベルを並べた幅」「行の見出しの幅」のうち最も大きいものにする。見出しは切らない。画面に収まらなければ横にスクロールする（MVP の spec §3.1 で、行を増やすときに決めるとしていた扱い）
- **電話番号の自動リンク**: iOS Safari が期間（`1789–1791` など）を電話番号とみなして下線付きのリンクにし、タップすると発信画面が開く。`index.html` に `<meta name="format-detection" content="telephone=no">` を足して止める（MVP の spec §5.2 の「`index.html` に入れるもの」に足す。画面に出る文言ではない）

## 5. UI 文言

MVP の spec §6・国・地域の spec §5 から変える・足すものだけ。

| 場所 | 文言 |
|---|---|
| 主題の選択肢（国・地域の表示の行の名前も同じ） | 王朝・政体 ／ 君主 ／ 首相・大統領 |
| 行の名前（データ） | フランク王国・フランス ／ イングランド・イギリス |
| 年の形式（1 年だけ） | `1871`（開始と終了が同じ年。circa が違えば `900頃–900` のように両方出す） |
| 年の形式（現在まで） | `1958–現在` |

## 6. 検証

- Vitest: 成果物の検証（`role`、終わりの `null`）、年の形式（1 年だけ、現在まで）、`timeRange`（現在まで）、`layoutLane`（1 年だけの棒の長さと段、現在まで続く棒、棒の外のラベルの位置）、`rowsForView`（主題 3 つ、国・地域の 3 行）、セレクトの値の相互変換
- 実ブラウザ（headless Chromium）: PC 幅と 375px 幅のそれぞれで、表示 5 通り × 向き 2 通りを確かめ、棒の外のラベルどうしが重ならないことを確かめる
