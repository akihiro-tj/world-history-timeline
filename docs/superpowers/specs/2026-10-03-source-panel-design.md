# 出典パネル 設計書

- 作成日: 2026-10-03
- 状態: レビュー待ち
- 前提: [2026-09-30-grouped-terms-design.md](./2026-09-30-grouped-terms-design.md)（以下「再登板の spec」）

## 1. 目的

年表のデータがどう作られているかを、利用者が年表の中で確かめられるようにする。棒を選ぶとパネルが開き、その値の出典（値を取った Wikipedia の記事）と、説が分かれていて 1 つを選んだところや記事と違う年にしたところはその理由が出る。

成功の基準:

- どの棒を選んでも、その値の出典をパネルからたどれる
- 説が分かれていて 1 つを選んだ値や記事と違う年には、その期間のすぐ下に理由の注記が出る
- 表示 6 通り × 向き 2 通りのすべてで、PC 幅と 375px 幅のどちらでも、パネルを開いた状態で棒・ラベル・行の見出しの配置が崩れない

## 2. スコープ

### 含めるもの

- 棒と棒の外のラベルを選べるようにする（クリック・タップ・キーボード）
- 選んだ項目の出典パネル（PC は右、スマホは下から）
- 成果物（`timeline.json`）に足すキー（§3）と、その検証（§7）
- DESIGN.md に、パネルの名前の文字の大きさ（`title`）とパネルの部品を足す

### 含めないもの

- 選んだ項目を URL に持たせること。選択はアプリの中の状態にする

## 3. データ（成果物の形）

再登板の spec の成果物から変えるところだけ。

```ts
// 出典: 値を取った Wikipedia の記事。label は画面に出す名前
type Source = { label: string; url: string };
type Dynasty = { id; name; kind; start; end; sources: Source[]; notes: string[] };
type Reign = { id; personId; name; role; title: string; start; end; sources: Source[]; notes: string[] };
```

- `sources` は 1 件以上。`label` は画面に出す名前そのもの（例: `Wikipedia「ステュアート朝」`、日本語版以外は `Wikipedia 英語版「House of Knýtlinga」`）。`url` は Wikipedia の記事
- `notes` は利用者に見える注記の文。説が分かれていて 1 つを選んだとき、記事と違う年にしたときだけ付く
- `title` は在位の地位（首相・大統領・イングランド女王など）。パネルの在位・在任の一覧に出す
- 人物（`Person`）は変えない

## 4. 選ぶ

- 棒と、棒の外のラベルを、どちらもボタンにする。クリック・タップのほか、Tab で移って Enter / Space でも選べる。キーボードで移ったときはフォーカスの枠（`primary`）を出す
- 選ぶ単位は、王朝ならその王朝、在位なら再登板の spec のまとまり（同じ行の、同じ人物・同じ表示名の在位）。国・地域の表示では君主と首相・大統領などが別の行になるので、同じ人物・同じ表示名でも役割が違えば別のまとまりにする。在位の棒を選ぶと、まとまりの棒すべてを選んだ状態にする
- 選んだ棒には `primary` の 2px の枠を付ける
- 主題や向きを切り替えても、選んだ項目が新しい表示にあれば選んだままにし、なければパネルを閉じる

## 5. パネル

### 出し方

- 幅 768px 以上: 年表の右に幅 360px のパネルを開き、年表はその分だけ狭くなる。選んだ棒が見えなくなったら、見える位置までスクロールする
- 幅 768px 未満: 画面の下から、高さの約半分のシートを出す。上の年表は操作できるままにし、選んだ棒（とラベル）を、見えている範囲（年の目盛りとシートの上端のあいだ）の上下・左右の真ん中まで、シートが滑り上がるのに合わせて滑らかにスクロールする。見えている範囲より大きい項目は、上端・左端を範囲の端にそろえる。全画面のあいだは年表を動かさず、半分の高さに戻したときにもう一度真ん中に合わせる
  - シートのどこを引いても動く（指が 8px 以上動いたら引く操作、それより短ければタップ）。引いているあいだは指に付いて動き、離すと全画面・半分・閉じるのうち近い位置へ 0.25 秒で収まる。速く弾いたときは、弾いた向きの次の位置へ進む
  - 半分の高さのときは中身をスクロールせず、続きは広げて読む。全画面のときは中身がスクロールし、いちばん上までスクロールした状態で下に引くとシートが動く
  - 開くときは下から滑り上がり、閉じるとき（× と Esc を含む）は下へ滑ってから消える。視差効果を減らす設定では動かさない
  - シートが開いているあいだは、年表の下端に余白を足し、いちばん下の棒も見えている範囲の真ん中まで持ち上げられるようにする
- × のボタンか Esc で閉じ、閉じたらフォーカスを選んでいた棒に戻す
- 年表を操作したままにするので、モーダルにはせず、名前付きの領域にする。開いたらフォーカスをパネルの名前に移す
- PC のパネルと年表の区切りは `divider` の線で表す。スマホのシートは年表に重なるので、上向きの柔らかい影と上の角丸 12px で区切る（DESIGN.md の Elevation & Depth の例外）
- 閉じるボタンは、薄い灰色の丸（直径 32px）の中に × のアイコンを置く。押せる範囲は 44px 角

### 中身

上から次の順に並べる。期間がパネルでいちばん知りたいことで、出典はその拠り所なので、本の脚注と同じく最後に置く。

1. **名前**: 王朝の名前、または在位の表示名
2. **期間・在位・在任**: 見出しは、王朝なら「期間」、君主なら「在位」、首相・大統領などなら「在任」
   - 王朝は期間を 1 行、在位はまとまりの在位を年の順に 1 行ずつ並べ、右に地位（`title`）を出す
   - 期間の書き方は、年表の棒と同じ（「頃」、「現在」）
   - 注記は、その王朝・在位の期間の行のすぐ下に、先頭に「※」を付けて出す。2 行目以降は「※」の後ろにそろえる
3. **出典**: `sources` を外部のページへのリンクとして縦に並べる。在位のまとまりでは、すべての在位の `sources` を年の順に集め、同じ URL は 1 つにする

### 文字

段の差は、大きさより太さと色でつける。パネルの中身は、年表のデータ（期間・地位）と、それに添えた注記の 2 種類なので、注記を一段小さい灰色にして、期間の並びを先に目で追えるようにする。

| 要素 | トークン | 見た目 |
|---|---|---|
| 名前 | `title`（新しく足す） | 18px 太字 |
| 節の見出し（出典・期間・在位・在任） | `heading` | 13px 太字、`muted` |
| 期間・地位・リンク | `body` | 16px。地位は `muted` |
| 注記 | `label` | 15px、`muted` |

### リンク

- 外部のページなので、新しいタブで開く（`target="_blank" rel="noopener noreferrer"`）
- リンクの文字の後ろに、新しいタブで開くことを示すアイコン（四角から矢印が出る形）を付ける。読み上げには「（新しいタブで開きます）」を足す
- リンクの色は `primary`、下線を付ける

## 6. UI 文言

`copy.ts` に足すものだけ。注記の文（`notes`）とリンクの名前（`sources` の `label`）はデータの側で持つ。

| 場所 | 文言 |
|---|---|
| パネルの領域の名前（読み上げ） | `出典` |
| 節の見出し | `出典`、`期間`、`在位`、`在任` |
| 注記の印 | `※` |
| 閉じるボタン | `×`（読み上げは `閉じる`） |
| 外部リンクの補足（読み上げ） | `（新しいタブで開きます）` |

## 7. 読み込みの検証

`parseTimeline` に足すもの。今と同じく、1 つでも外れたら全体を読み込まず、読み込めなかったことを出す。

- 知らないキー・足りないキーがあれば弾く（今と同じ）
- `title` は空でない文字列
- `sources` は 1 件以上で、各件は `label`（空でない文字列）と `url` を持つ。`url` は `https://<言語コード>.wikipedia.org/` で始まるものだけを通す（言語コードは英小文字とハイフン）
- `notes` の各文は空でない文字列

## 8. DESIGN.md

- `typography` に `title`（18px、太さ 600、行の高さ 1.4）を足し、`pnpm tokens` で `theme.css` を作り直す
- Typography に `title`（出典パネルの名前）、`label`・`heading`・`body` の用途にパネルの要素を足す
- Components に出典パネル（`source-panel`）、パネルの名前（`source-panel-title`）、節の見出し（`source-panel-heading`）、出典のリンク（`source-link`）、注記（`source-note`）、選んだ棒の枠（`selected-bar`）を足す
- Layout に §5 の出し方を足す
- `rounded` に `lg`（12px）を足し、スマホのシートの上の角に使う。Elevation & Depth に、スマホのシートだけ影を付ける例外を足す（値は `src/app/index.css` の `--shadow-sheet`）。Components に閉じるボタン（`source-panel-close`）を足す

## 9. 検証

- Vitest:
  - `parseTimeline`: §7 の規則（通る例と弾かれる例。言語コード付きの Wikipedia は通り、ほかのサイトは弾かれる。`sources` が空なら弾かれる）
  - パネルの中身を作る関数: 出典の並び（在位のまとまりは `sources` を年の順に集め、同じ URL を 1 つに）、在位・在任の一覧（年の順、地位、注記、表示名が違えば別のまとまり）、節の見出し（期間・在位・在任）
  - 表示を切り替えたあとの選択（新しい表示にあれば残し、なければ閉じる）
- 実ブラウザ（headless Chromium）: PC 幅と 375px 幅のそれぞれで、表示 6 通り × 向き 2 通りのすべてについて、パネルを開いた状態で次を確かめる
  - 選んだ棒の枠が出て、パネルに隠れずに見えている
  - 棒・ラベル・行の見出しの位置が、パネルを開く前と変わらない（ボタンにしたことで配置が崩れない）
  - 長い注記がパネルの中で折り返す
  - 操作: Tab で棒に移って Enter で開く、Esc で閉じてフォーカスが棒に戻る、別の棒を押すと中身が入れ替わる、375px 幅でシートのどこを引いても全画面・半分・閉じるに収まる（マウスとタッチ）、弾くと次の位置へ進む、全画面で中身をスクロールしてから下に引くとシートは動かない、引いた直後にリンクが開かない、選んだ棒が見えている範囲の真ん中に来る（表示 6 通り × 向き 2 通り）
