# 棒の名前の貼り付けと「次の駅」の案内 設計書

- 作成日: 2026-10-04
- 状態: 承認済み
- 前提: [2026-09-27-world-history-timeline-design.md](./2026-09-27-world-history-timeline-design.md)（以下「MVP の spec」）、[2026-10-04-rough-years-design.md](./2026-10-04-rough-years-design.md)（以下「世紀単位の spec」）

## 1. 目的

古代オリエントのデータで年表が前 3000 年ごろまで延び、長い棒や、長いあいだ何もない行が増えた。スマホの横向きでは次のことが起きる。

- エジプト古王国のような長い棒は、名前と期間が棒の始まりにしか書かれていない。スクロールすると灰色の帯だけが残り、何の棒か分からない
- 前 2500 年あたりのメソポタミアのように、見えている範囲に棒が 1 本もない行は空っぽに見える。どちらへスクロールすれば棒があるか分からない

そこで次の 2 つを足す。

- 棒が画面にかかっているあいだ、棒の中の名前と期間を画面の端に貼り付ける（§3）
- 見えている範囲が空の行に、両側のいちばん近い棒の名前を出す。タップすると、その棒までスクロールする。電車の「次の駅」の案内にあたる（§4）

成功の基準:

- 主題 4 つ × 向き 2 通りのすべてで、長い棒の名前と期間が、棒が画面にかかっているあいだ読める
- 見えている範囲が空の行には、棒がある側に案内が出る。案内をタップすると、その棒が見えている範囲の中ほどに来る
- PC 幅と 375px 幅のどちらでも、案内が行の名前・棒・年の目盛りに重ならない

## 2. スコープ

### 含めるもの

- 棒の中の文字の貼り付け（§3）
- 見えている範囲が空の行の案内と、タップでのスクロール（§4）
- 案内の読み上げの文言（§5）

### 含めないもの

- 棒の外に出したラベルの貼り付け。短い棒は画面からはみ出しにくい。再登板で期間が 2 行以上ある在位の長い棒が出てきたら、そのときに考える
- 棒が見えている行での、画面の外の棒の案内
- 案内からの出典パネルの表示

## 3. 棒の名前の貼り付け

**対象**: 名前と期間を棒の中に書いている棒（`inside` が `row` か `stack` の棒）。

**動き**:

- 横向き: 棒の始まりが年表の左端より左に出ると、棒の中の文字が年表の左端（`spacing.xs` の余白）に貼り付く
- 縦向き: 棒の始まりが行の見出し（上端の 32px）の下に隠れると、棒の中の文字が見出しのすぐ下に貼り付く
- 棒の終わりが近づくと、文字は棒の終わりに押されて一緒に流れ、棒の外にははみ出さない
- 幅のある端（世紀単位の spec §4）は、貼り付く前は今と同じく、ぼかしの後ろから書き始める

**作り**: 棒のボタンの `overflow: hidden` を `overflow: clip` にする（`hidden` だと棒がスクロールの入れ物になり、中の `sticky` が年表のスクロールに効かない）。棒の中の文字を 1 つの要素で包み、横向きは `position: sticky; left`、縦向きは `position: sticky; top` を付ける。横向きの行の名前は棒より上の段にあるので重ならない。

## 4. 「次の駅」の案内

**出すとき**: 見えている範囲に、その行の棒も棒の外のラベルも 1 つもかかっていない行にだけ出す。見えている範囲より前（横向きは左、縦向きは上）でいちばん近い棒と、後ろ（右・下）でいちばん近い棒を、あるほうだけ出す。棒が 1 本もない行には出さない。

- いちばん近い棒: 前は、ラベルを含めた終わりの位置がいちばん遅い棒。後ろは、始まりの位置がいちばん早い棒。同じ位置なら段の小さい棒
- 見えている範囲（時間軸方向）: 横向きは年表の左端から右端まで。縦向きは行の見出しの下から年表の下端まで。スマホで出典シートが開いているときは、シートの上端まで

**見た目と位置**:

- 横向き: 行の 1 段目（棒と同じ高さ）の、年表の左端に「‹ 名前」（左向きのシェブロン）、右端に「名前 ›」（右向き）を貼り付ける
- 縦向き: 列の、行の見出しのすぐ下に上向きのシェブロンと名前、年表の下端（シートが開いていればシートの上端）に下向きのシェブロンと名前を貼り付ける
- 向きの印は文字の矢印ではなく SVG のシェブロンのアイコンにする（文字の矢印は OS やフォントで見え方が変わるため。向きの切り替えボタンと同じく `src/app/icons.tsx` に置く）。大きさは 12px、色は `muted`。飾りとして扱い、読み上げない
- 文字は棒の外のラベルと同じ `caption`・`on-surface`。`border` の枠と角丸 `sm` で囲み、地は `surface`。押せる範囲の太さは横向きの棒と同じ 36px。列に収まらない名前は末尾を省略記号で切る
- 色・角丸・余白は既存のトークンだけで作る。DESIGN.md の部品に `offscreen-cue` を足す

**タップしたとき**: 後ろの案内なら棒の始まりを、前の案内なら棒の終わりを、見えている範囲の中ほどに置くまで滑らかにスクロールする（視差効果を減らす設定では、すぐに移動する）。スクロールできる範囲を越えるときは端で止める。出典パネルは開かない。

**キーボード**: 案内は Tab の順に入れない（着くと案内が消え、フォーカスの行き場がなくなるため）。年表はこれまでどおりキーボードでスクロールできる。

**作り**:

- `src/timeline/nearby.ts`（新規）: 1 行の棒の位置（時間軸方向の始まりと、ラベルを含めた終わり）と見えている範囲を受け取り、範囲にかかる棒があれば `null`、なければ前後のいちばん近い棒（なければ `null`）を返す純粋な関数
- `src/timeline/layout.ts`: `BarLayout` に、棒の外のラベルを含めた時間軸方向の終わりの位置を足す
- `src/timeline/scroll.ts`: 指定した位置を見えている範囲の中ほどに置くスクロール量を、スクロールできる範囲に収めて返す関数を足す
- `src/timeline/Timeline.tsx`: スクロールのたびに行ごとの案内を計算し、変わったときだけ描き直す。案内の層を行全体に広げ、両端の案内に `sticky` を付ける

## 5. UI 文言

MVP の spec §6 に足す。

| 場所 | 文言 |
| --- | --- |
| 案内の表示 | シェブロンのアイコン（文言なし）と棒の名前（データの名前） |
| 案内の読み上げ（`aria-label`） | 「{名前}へ移動」（例:「アッカド王国へ移動」） |

## 6. 検証

- `nearby.ts` と `scroll.ts` の関数を Vitest で確かめる。範囲の端に接する棒、棒の外のラベルだけが範囲にかかる場合、片側にしか棒がない場合、棒のない行、スクロールできる範囲の端で止まる場合
- 実ブラウザで、PC 幅と 375px 幅のそれぞれで、主題 4 つ × 縦・横を確かめる。375px 幅の縦向きは、出典シートを開いた状態も確かめる
- 実装の前に、HTML のモックを Artifact で公開してデザインレビューを受ける
