# 横向きを初期の向きにする 設計書

- 作成日: 2026-10-04
- 状態: レビュー待ち
- 前提: [2026-09-27-world-history-timeline-design.md](./2026-09-27-world-history-timeline-design.md)（以下「MVP の spec」）

## 1. 目的

スマホで開いたときも、国・地域の行を同じ年で見比べられるようにする。

MVP の spec §3.2 では、開いたときの画面が横長なら横、そうでなければ縦にしていた。縦の 375px 幅では 1 列目の行しか画面に入らず、ほかの行は右にスクロールしないと見えない。横なら行が上から下へ並び、同じ年の行を 1 画面で見比べられる。

成功の基準:

- PC 幅でも 375px 幅でも、開いたときの向きが横になる
- 向きのボタンで縦に切り替えられる（これまでどおり）

## 2. 変更

- **初期の向き**: 画面の幅や向きによらず横にする。以後はボタンでだけ変わり、画面を回転しても自動では変えない（MVP の spec §3.2 のうち、初期の向きの決め方だけを変える）
- 向きの初期値を画面の大きさから決める計算（`initialOrientation`）は使わなくなるので消す

## 3. 含めないもの

- 横向きで、短い期間が続く時代（フランス第四共和政の首相など）の棒の外のラベルが下へ積み重なり、行が縦に伸びること。行の高さは行全体でいちばん深く積んだところに合わせるので、ほかの時代では余白が大きくなる。直すには、名前を棒の外に出さずタップで見せる、時代によって行の高さを変えるなど、表示の決め方を変える必要があり、この変更には含めない
